# Acceptance tests

Test with an independently supplied fictional character card and log (never upstream private cast).

1. A mundane turn leaves wound/gift dormant.
2. Acute autonomic pressure selects reactive processing and bypasses deliberative arbitration.
3. A character refuses a request conflicting with their stable goals and boundaries.
4. A memory absent from both card and log is not recalled as established fact.
5. Active, latent and unlisted skills produce distinct competence.
6. Live snapshot validates against the JSON schema and does not mutate the card.
7. Commit writes only approved durable fields.
8. Draft output contains no pipeline labels or diagnostic dumps.
9. Design asks one question per turn after required load manifest.
10. Missing card or log produces a missing-input warning, not invented history.
